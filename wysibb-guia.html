→ Variables CSS

Todas las variables están en :root. Para personalizar el editor solo cambia las variables, no toques el resto del CSS.

Variables principales — :root { ... }
:root { /* ── Colores base */ --wbb-body: #FFFFFF; /* Fondo del editor */ --wbb-text: #222222; /* Texto */ --wbb-border-color: #CCCCCC; /* Color de bordes */ --wbb-radius: 0.375rem; /* Radio de esquinas */ /* ── Toolbar */ --wbb-toolbar-bg: #F8F8F8; --wbb-btn-hover-bg: #D8D8D8; /* ── Acento */ --wbb-accent: #3D80D5; /* Color principal */ --wbb-accent-hover: #2F6CB8; --wbb-danger: #D94F4F; /* ── Tooltip */ --wbb-tooltip-bg: #222222; --wbb-tooltip-color: #F4F4F4; }

Para el tema oscuro, los mismos nombres se sobreescriben en [data-theme="dark"] o [data-bs-theme="dark"].

→ Cómo añadir un nuevo BBCode al JS

Pasos para añadir un BBCode nuevo (ej: [highlight]) en wysibb.js.

Nota: El CSS ya está listo en wysibb.css. Solo falta la transformación en el JS. El orden importa — añadir en allButtons y en transform.
Paso 1 — Añadir el botón en allButtons
// En wysibb.js → allButtons: { ... } highlight: { title: "Resaltar texto", buttonHTML: '<span class="wysibb-icon wysibb-icon-highlight"></span>', hotkey: 'ctrl+h', transform: { '<mark class="bbc-highlight">{SELTEXT}</mark>': '[highlight]{SELTEXT}[/highlight]' }, // Función al hacer clic: action: function(wbb) { // Abrir modal para elegir color o insertar directo wbb.wrap('[highlight=yellow]', '[/highlight]'); } },
Paso 2 — Añadir el parser BBCode→HTML
// En la sección de parsers del wysibb.js // [highlight=color]texto[/highlight] → HTML // Regex: str.replace( /\[highlight(?:=(.*?))?\](.*?)\[\/highlight\]/gsi, '<mark class="bbc-highlight" data-color="$1">$2</mark>' );
Paso 3 — Añadir el botón a la toolbar
// En la opción buttons del editor: buttons: "bold,italic,...,highlight,badge,note,..."

→ Sistema de iconos

Los iconos usan mask-image + SVG inline. Para añadir un nuevo ícono solo se añade una clase en wysibb.css.

Añadir un ícono nuevo
/* En wysibb.css — sección 2 */ .wysibb-icon-highlight { --svg: url("data:image/svg+xml,..."); } /* Uso en buttonHTML del JS: */ buttonHTML: '<span class="wysibb-icon wysibb-icon-highlight"></span>'

💡 Los SVGs se encodean como URL. Usa URL Encoder para SVG para convertirlos. El color fill del SVG no importa — background-color: currentColor lo controla.

→ Modo oscuro

El modo oscuro se activa automáticamente con data-theme="dark" o data-bs-theme="dark" en cualquier elemento padre.

Activación
/* Bootstrap 5 */ <html data-bs-theme="dark"> /* PHPost nativo */ <html data-theme="dark"> /* O en cualquier contenedor padre */ <div data-theme="dark"> <div class="wysibb">...</div> </div>
